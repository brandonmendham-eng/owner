# Sandfire Crusade ⚔ The Burning Valley

A castle-building siege RTS in the spirit of *Stronghold Crusader*, packed into a single HTML file.
Open `index.html` in any modern browser. No install or build step is needed.

## The level
A 112×112 river valley with up to **four rival AI lords**, each with their own personality:

| Lord | Style |
|---|---|
| **Varric the Iron**, The Relentless | Early, frequent heavy-infantry assaults |
| **Sultana Zahra**, The Desert Wind | Cavalry raids and massed archers |
| **Baron Mordel**, The Patient | Rings his keep in walls, then rolls in with catapults |
| **Ser Halbrecht**, The Opportunist | Preys on whichever lord is weakest |

The lords build walled castles, run their own economies, and send attack waves at you **and at each other**.
Destroy every rival keep to win. Lose your keep and it's over.

## Features
- **Economy:** wood, stone, food and gold, plus peasants, housing, popularity and taxes.
- **Buildings:** hovels, farms, woodcutters, quarries, chapels, barracks, drag-to-build walls, gatehouses and archer towers.
- **Units:** spearmen, archers, macemen, swordsmen, knights and catapults (splash damage, wall-smashing).
- **Siege:** units smash through enemy walls and gates when no path exists.
- **Settings:** 3 difficulties and 2–4 rivals. The map is randomly generated every game.
- **Interface:** minimap, zoom, speed 1–3×, pause, sound effects, and a live AI-vs-AI battle behind the title screen.

## Controls
| Input | Action |
|---|---|
| WASD / arrows / screen edge | Scroll |
| Mouse wheel | Zoom |
| Left-drag | Select soldiers |
| Double-click | Select all of that type |
| Right-click | Move / attack |
| Shift + right-click | Attack-move |
| Space | Select whole army |
| 1–9 | Build hotkeys |
| H | Jump home |
| G | Jump to latest alert |
| P | Pause |
| Del | Demolish |
| Right-click with Barracks selected | Set rally point |

# Primal Shores 🦖 Survive · Tame · Conquer

A dino survival game in the spirit of *ARK*, also packed into a single HTML file.
Open `primal-shores/index.html` in any modern browser.

You wash up on a randomly generated island. Punch trees, craft tools, build a base, knock out dinosaurs and tame them, then ride your army up the volcano to slay the **Alpha Rex**.

## Features
- **Procedural island:** beaches, grasslands, jungle, highlands, snow peaks and a volcano with ash fields and a lava crater. Terrain has hill shading and a day/night cycle with dynamic lighting from campfires, forges and lava.
- **Survival:** health, stamina, food and water. Swimming drains stamina, you freeze on the snow peaks at night, and lava burns.
- **Gathering:** trees, rocks, metal, berry bushes and carcasses. Each tool gives different yields (pick for stone and metal, hatchet for wood, flint and hide).
- **22 engrams that unlock as you level:** tools, a club, spear, bow, stone and tranq arrows, armor, campfire, forge, metal gear, plus walls, doors, floors and sleeping bags.
- **Taming:** fill a dino's torpor with a club or tranq arrows, then feed it berries (herbivores) or meat (carnivores) before it wakes up.
- **9 species:** Dodo, Parasaur, Triceratops, Stegosaurus, Raptor, Carnotaurus, Rex, Mammoth and Direwolf. Each has its own temperament (passive, skittish, neutral or aggressive), and wild levels run 1–45.
- **Tames:** they follow, stay, defend you and attack your target. Ride them to fight and to harvest (Trikes and Stegos strip berry bushes, Mammoths fell trees).
- **Base building:** grid-placed walls, doors, floors, campfires, forges and beds. Wild dinos smash walls to reach you.
- **Boss:** the Alpha Rex guards the volcano.
- **Persistence:** you drop a loot bag when you die and respawn at a sleeping bag. The game autosaves to your browser.

## Controls
| Input | Action |
|---|---|
| WASD / arrows | Move (Shift to sprint) |
| Hold left-click | Attack / harvest |
| Tab or I | Inventory and crafting |
| 1–0 | Hotbar (tools and structures) |
| E | Feed a knocked-out dino / hold to drink near water |
| Q | Eat |
| R | Ride / dismount a tame |
| F | Whistle: follow / stay |
| T | Switch arrow type |
| X | Pick up the structure under the cursor |
| M | Full map |
| Mouse wheel | Zoom |
| P | Pause |
