# Sandfire Crusade ⚔ The Burning Valley

A castle-building siege RTS in the spirit of *Stronghold Crusader*, packed into a single HTML file.
Open `index.html` in any modern browser. No install or build step is needed.

## The level
A 112×112 river valley with up to **four rival AI lords**, each with their own personality:

| Lord | Style |
|---|---|
| **Varric the Iron**, The Relentless | Early, frequent heavy-infantry assaults |
| **Sultana Zahra**, The Desert Wind | Cavalry raids and massed archers |
| **Baron Mordel**, The Patient | Rings his keep in walls, then rolls in with catapults |
| **Ser Halbrecht**, The Opportunist | Preys on whichever lord is weakest |

The lords build walled castles, run their own economies, and send attack waves at you **and at each other**.
Destroy every rival keep to win. Lose your keep and it's over.

## Features
- **Economy:** wood, stone, food and gold, plus peasants, housing, popularity and taxes.
- **Buildings:** hovels, farms, woodcutters, quarries, chapels, barracks, drag-to-build walls, gatehouses and archer towers.
- **Units:** spearmen, archers, macemen, swordsmen, knights and catapults (splash damage, wall-smashing).
- **Siege:** units smash through enemy walls and gates when no path exists.
- **Settings:** 3 difficulties and 2–4 rivals. The map is randomly generated every game.
- **Interface:** minimap, zoom, speed 1–3×, pause, sound effects, and a live AI-vs-AI battle behind the title screen.

## Controls
| Input | Action |
|---|---|
| WASD / arrows / screen edge | Scroll |
| Mouse wheel | Zoom |
| Left-drag | Select soldiers |
| Double-click | Select all of that type |
| Right-click | Move / attack |
| Shift + right-click | Attack-move |
| Space | Select whole army |
| 1–9 | Build hotkeys |
| H | Jump home |
| G | Jump to latest alert |
| P | Pause |
| Del | Demolish |
| Right-click with Barracks selected | Set rally point |
